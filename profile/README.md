# Setup Problems and Practical Fixes

If InvGate Assets does not discover expected devices, verify network connectivity, firewall configuration, discovery credentials, and inventory scanning settings. Ensure supported operating systems are accessible, discovery services are enabled, and administrative permissions allow inventory collection.

For incomplete inventory results, verify network segmentation, credential permissions, endpoint accessibility, and scheduled discovery configuration before performing another inventory synchronization.
